Install App

  1. The app page has opened in your browser (or a new tab).
  2. Tap the browser menu ⋮ or Share icon ⬆.
  3. Select Add to Home Screen or Install app.
  4. On desktop Chrome/Edge: look for the install ⊕ icon in the address bar.
  5. Confirm the prompt — the app installs like a native app.

The dashboard cannot remotely install a PWA on another device. Share the direct link with the driver or controller and they install it from their own browser.
